# 2026-10-27 歷史比較摘要

[JSON 摘要](2026-10-27.json) 是原調查 artifacts 的白名單匯出，**不是這個新倉庫執行的結果**。只保留數字、ID 排名與 hash；第三方新聞／字幕／snippet 不在此目錄。

## 名稱對應

| 新倉庫名稱 | 舊實驗 | 歷史狀態 |
| --- | --- | --- |
| B0 | Stock、無應用正規化 | 未跑，不填數字 |
| B1 | matched-barebone-engine，Stock＋正規化 | 34 真實文件／60 查詢；未跑完整新合成 suite |
| B2 | A，外置 COCT＋原二次切分 | 真引擎 HTTP |
| B3 | B，外置 COCT＋停用二次切分 | 真引擎 HTTP |
| B4 | C，B3＋連續片段 reference | 記憶體參考，非完整 Meili 端到端 |

全量 dictionary API 是獨立診斷組，沒有頻率、沒有替換 Jieba 主庫，不納入 B 序列。早先內嵌 COCT 主庫對照的 ID 排名變化也以獨立描述保留，不能冒充外置 A/B 的新測量。

## 聚合結果

| 開發合成集 23 文件／22 查詢 | B2 | B3 | B4 參考 |
| --- | ---: | ---: | ---: |
| Expected 命中 | 32/38 | 32/38 | 38/38 |
| Forbidden 誤收 | 3/468 | 3/468 | 0/468 |
| 完整 membership 通過查詢 | 14/22 | 14/22 | 22/22 |

B2／B3 同樣漏部分詞內片段與單字，也誤收「觀 光」及「半年／導師」；單純關閉二次切分沒有達成規則。B4 透過獨立 posting 補回並檢查連續性，沒有從 gold 選詞或改原 gold。

real-34 原題庫 50 個 expected pairs，B1／B2／B3／B4 均命中 49，唯一既有 miss 是 M30 台績電→應命中的台積電原文件。這不表示行為完全相同，也不是完整 precision：原真實集沒有 forbidden pairs。B3→B4 新增股、電、金、利率的部分文件 ID，完整差異保存在 JSON，沒有因無新 gold miss 就隱藏召回變動。

B4 的「導體」排序案例兩個候選都有出現、順序正確；「股」實際定位到個股中的股；三個原文映射案例通過。但它只保留 B3 既有 ID 排序、再追加新召回者，沒有一般完整詞優先計分規則。26 個無漢字真實查詢繼承 B3，並非新的英文檢索驗證。岸風等跨 COCT 詞界結果仍是無 gold 的探索輸出。

## 時間與限制

B2 的 HTTP p50／p95 為 5.47／53.36ms，B3 為 4.70／59.19ms；各 180 次暖查詢，單機小資料。p50 改善而 p95 上升，不能宣稱 B3 普遍較快。B4 約 0.007／1.73ms 是只計記憶體 reference 函式、使用預先記錄 B3 輸入的時間，**不可與 HTTP 比較或當作端到端速度**。

另一次全量 dictionary API 診斷的 p50 約 473ms，風電由 5 筆降為 0、漏掉明定正例；帶頻率主庫保留能源新聞。這是接法差異，不是單憑詞頭多就能決定品質。

所有題目已用於開發調查，沒有獨立 holdout 成績。新倉庫重跑必須另外記錄來源／時間／run id，不覆寫歷史結果。資料、指標與授權邊界見 [datasets](../../docs/datasets.md) 與 [methodology](../../docs/methodology.md)。
